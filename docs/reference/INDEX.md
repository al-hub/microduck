## 관리 원칙
- 공식 코드 전체 ZIP을 이 저장소에 재배포하거나 복사하지 않습니다.
- 상류(upstream) 코드는 https://github.com/pollen-robotics/microduck 에서 직접 읽습니다.
- 기술 사실은 **공식 원문 우선**, 본문 요약은 탐색 도우미입니다. 미확정 수치·기능은 확인됨으로 취급하지 않습니다.
- 실제 구현 전 최신 upstream 커밋과 문서 변경을 확인하고 필요 시 기준일을 갱신합니다.
- GitHub Issue에 요구사항/검증 결과를 기록하며 이 인덱스는 문서 중복을 피합니다.
