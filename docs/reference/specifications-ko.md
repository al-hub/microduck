# Microduck 공개 사양 한국어 요약 (비공식)

기준일: 2026-10-24. 출시 전 공개자료를 정리한 **참고용 요약**이며, 최종 배송 제품과 차이가 있을 수 있습니다.

원문: https://pollen-robotics.com/microduck/press-kit/

| 구분 | 사전 수집된 공개 사양 |
|---|---|
| 크기 | 높이 25 cm · 너비 14 cm |
| 무게 | 800 g 미만 |
| 구동 | 자유도 15 · 관절 모터 15개 |
| 프로세서 | Rockchip RK3566 (AI 가속기) |
| 메모리/저장공간 | RAM 1 GB / 저장소 32 GB |
| 카메라 | 전면 카메라 및 촬영 표시등 |
| 거리 감지 | 8×8 ToF LiDAR |
| 자세 센서 | 몸통·머리 IMU 각 1개 |
| 오디오 | 마이크와 스피커 |
| 통신 | Wi-Fi, Bluetooth, NFC 안테나 2개 |
| 배터리 | 탈착형 NP-F550 2600 mAh |
| 사용 시간 | 약 1시간(환경에 따라 달라짐) |
| 제어 | 50 Hz 루프 |
| 소프트웨어 | 공식 오픈소스, Rust / JSON-RPC / WebRTC / MuJoCo 관련 코드 참조 |

## 검증 전까지 확정하지 말 것
- 카메라 해상도/FOV, LiDAR 측정거리, 무선 규격 상세, SDK 언어 범위
- 유튜브 음악 스트리밍·Bluetooth 스피커 모드·한국어 대화의 기본 지원
- 자동 충전, IR 송신, 물체 파지 하중, 실내 완전 자율 이동
- 날씨/교통 확인을 위한 자율 위치 이동·사진 촬영·상황 설명의 기본 지원

위 기능의 **구현 가능성**과 **기본 탑재 여부**는 별개입니다. 공식 API 및 배송 후 실제 기기를 대상으로 확인하십시오.
